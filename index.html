My Princeton local setup

PrincetonLive includes a browser-only setup panel where residents can save a street name and resident modes such as family, no car, culture, and rain plan. It uses that local profile to highlight garbage pickup, commute shortcuts, event filters, and neighborhood context without creating an account or uploading an address.

Neighborhood context for Princeton, NJ

The neighborhood map uses public aggregate data only. It combines Census block-group geometry, ACS estimates, National Weather Service and civic links, and official voting-result sources. It does not publish individual voter, household, or address-level records.

PrincetonLive FAQ

What is PrincetonLive?

PrincetonLive is an independent daily operating guide for Princeton residents and new arrivals.

Is PrincetonLive official?

No. It is independent and links to official sources for authoritative details.

What data sources does it use?

It uses public weather, event, municipal, library, Census, transit, and election-result sources.

Does the neighborhood map show individual people?

No. It uses aggregate public data and avoids individual household, voter, and address-level records.
